# Data

All data files are re-generated by running the pipeline.
Do not commit raw or processed data files to this repository.

## Sources

| Series | Source | Ticker / ID | Frequency |
|--------|--------|-------------|-----------|
| SPY adjusted close | Yahoo Finance via yfinance | SPY | Daily |
| AAPL adjusted close | Yahoo Finance via yfinance | AAPL | Daily |
| JPM adjusted close | Yahoo Finance via yfinance | JPM | Daily |
| CBOE Volatility Index | FRED API | VIXCLS | Daily |
| 10-Year Treasury Yield | FRED API | DGS10 | Daily |

## Period
January 2013 – December 2025

## Reproduction
1. Add your FRED API key to `.env` as `FRED_API_KEY=your_key`
2. Run `python src/step1_data.py`
3. Run `python src/step2_features.py`
